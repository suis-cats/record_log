研究レコーダー Windows ポータブル版

必要なソフト
- Windows 10/11 64bit
- OBS Studio（OBS WebSocketを有効化）
- ActivityWatch（aw-watcher-window と aw-watcher-afk を起動）

使い方
1. ZIPをローカルディスクへ展開します。
2. OBSで、実カメラだけを表示するシーンを仮想カメラへ出力できるようにします。
3. ActivityWatchを起動します。
4. ResearchRecorder.exeを実行します。
5. 初回画面で参加者ID、保存先、マイク、OBS WebSocketパスワードを設定して「設定を保存」を押します。
6. 準備完了後に自動で記録が始まります。

記録中に画面を閉じてもトレイで継続します。「停止して保存」またはトレイの「終了」でファイルを確定してください。
キーの内容は保存せず、キー入力・クリック・スクロール・マウス移動の時刻と量だけを保存します。
